## 安装

**Windows：**下载 `.exe`，双击并按安装向导操作，可以选择安装位置。当前安装程序尚未进行代码签名，Windows 可能提示“未知发布者”。

**macOS：**下载 `.dmg`，打开后将 Notely 拖到 Applications。当前版本未经过 Apple 公证；首次启动可在 Finder 右键选择“打开”，或前往“系统设置 → 隐私与安全性”允许。
